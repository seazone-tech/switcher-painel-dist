# Contas Claude (instaladores)

App de bandeja da Seazone para o pool de contas do claude-switcher: mostra todas as contas com o
uso de cada uma, troca de conta sozinho quando a sua esgota (conferindo ao vivo se a nova tem
crédito) e acorda as sessões do Claude Code que pararam por limite. Sem terminal.

Este repositório só guarda os pacotes (releases); o código fica em `seazone-tech/switcher-painel`.

## Instalar (Windows)

1. Baixe o `ContasClaude-windows-<versão>.zip` da release mais recente e extraia.
2. Clique duas vezes em `Instalar.cmd` (instala para o seu usuário, sem administrador, e cria o
   atalho "Contas Claude" no Menu Iniciar).
3. Na primeira abertura, clique em "Entrar com a conta Google" (conta @seazone.com.br). O app
   prepara o resto sozinho e, se você tinha o switcher de terminal, tira o antigo (era ele que
   piscava um terminal a cada 15 min).

O app confere este repositório e se atualiza sozinho. macOS e Linux: em preparação.
